### 5.1.2.1 기본 변수
- 괄호({})로 시작하는 경우에는 큰따옴표("")를 반드시 사용해야 함
```bash
[vagrant@ansible-controller vars_test]$ vim debug.yaml

---
- name: This is vars test
  hosts: localhost
  vars:
    vars01: test playbook vars
  tasks:
    - name: print msg vars only
      ansible.builtin.debug:
        msg: "{{ vars01 }}"
    - name: print msg vars plus test
      ansible.builtin.debug:
        msg: "{{ vars01 }} test"
    - name: print msg text plus vars
      ansible.builtin.debug:
        msg: "test {{ vars01 }}"
...

```
```bash
---
- name: This is vars test
  hosts: localhost
  vars:
    vars01: test playbook vars
  tasks:
    - name: print msg vars1
      ansible.builtin.debug:
        msg: "{{ vars01 }}"
    - name: print msg vars2
      ansible.builtin.debug:
        msg: "{{ vars01 }}"
      vars:
        vars01: test task vars
    - name: print msg vars3
      ansible.builtin.debug:
        msg: "{{ vars01 }}"
...
```

## 5.1.3 변수의 우선 순위
- 가장 마지막이 우선 순위가 높음

> 1. 명령의 옵션 (예: -u my_user)
> 2. 역할의 기본(defaults) 변수 파일(role_defaults_main.yml)
> 3. 인벤토리 파일의 그룹 변수 / 동적 인벤토리 스크립트의 그룹 변수
> 4. 인벤토리 파일이 있는 겨올의 group_vars/all 파일
> 5. 플레이북 파일이 있는 경로의 group_vars/all 파일
> 6. 인벤토리 파일이 있는 경로의 group_vars/* 모든 파일
> 7. 플레이북 파일이 있는 경로의 group_vars/* 모든 파일
> 8. 인벤토리 파일의 호스트 변수 / 동적 인벤토리 스크립트의 호스트 변수
> 9. 인벤토리 파일이 있는 경로의 host_vars/* 모든 파일
> 10. 플레이북 파일이 있는 경로의 host_vars/* 모든 파일
> 11. 호스트의 팩트 변수 / set_fact 모듈에 의해 캐시된 변수
> 12. 플레이의 vars 키워드
> 13. 플레이의 vars_prompt 키워드
> 14. 플레이의 vars_files 키워드
> 15. 역할의 vars 변수 파일(role_vars_main.yml)
> 16. 블록의 vars 키워드
> 17. 작업의 vars 키워드
> 18. include_vars 모듈
> 19. set_facts 모듈 / 등록 변수
> 20. 역할 (또는 include_role 모듈)의 파라미터
> 21. include 모듈의 파라미터
> 22. ansible-playbook 명령의 --extra-vars 변수

```bash

- name: test lookup plugin
```

```bash
    - name: username
      prompt: Enter username
      private: no
      default: admin
  vars:
    myvars: bac
  tasks:
    - name: print vars
      ansible.builtin.debug:
        msg: "{{ myvars | default('abc') }}"
...
```
