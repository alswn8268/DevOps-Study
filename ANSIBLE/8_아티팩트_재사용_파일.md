# 8.1 변수 재사용
- ansible 플레이북 작성 시 하나의 매우 큰 파일에 플레이 및 작업을 작성할 수 있지만, 단일 플레이북의 복잡한 작업을 다른 파일로 나누어 작업 집합으로 구성하는 것이 유지보수에 용이함
- 더 작고 분산된 아티팩트를 통해 변수, 작업 및 플레이를 여러 플레이북에서 재사용할 수 있음

## 8.1.1 플레이북에서 변수 재사용
- 플레이북에서 vars_files 키워드 및 include_vars 모듈을 사용하여 외부 변수 파일을 가져올 수 있음

# 8.2 작업 재사용
- 플레이북, 플레이, 작업 일부, 변수를 재사용하기 위해 `include_*` 및 `import_*` 모듈을 사용할 수 있음

## 8.2.1 include 모듈
- `include_*` 관련 모듈은 플레이, 작업, 변수를 포함할 수 있으며 동적으로 플레이북에 추가됨
- 이전 작업 결과에 영향을 받을 수 있음
- 주로 반복문에서 사용됨

## 8.2.2 import 모듈
- `import_*` 관련 모듈은 플레이북, 역할, 작업을 가져올 수 있으며 정적으로 플레이북에 추가됨
- 이전 작업의 결과에 영향을 받지 않음


```bash
[vagrant@ansible-controller second]$ vi include.yaml

---
- name: Play1
  hosts: localhost
  vars_files:
    - vars/myvars.yaml
  tasks:
    - name: task1
      debug:
        msg: "{{ myvars }}"
    - name: task2
      debug:
        msg: "{{ myvars }}"
...

[vagrant@ansible-controller second]$ mkdir vars
```

### 플레이북 모듈화 작업
1. 웹서버 구성 플레이북을 작성

```bash
[vagrant@ansible-controller-prac playbook]$ vi webserver.yaml
[vagrant@ansible-controller second]$ ansible-galaxy collection install ansible.posix

---
- name: This playbook is webserver config
  hosts: localhost
  become: true
  tasks:
    - name: Package Install
      ansible.builtin.yum:
        name: httpd
        state: latest
    - name: Service Enabled
      ansible.builtin.service:
        name: httpd
        state: started
        enabled: true
    - name: Firewall Setting
      ansible.posix.firewalld:
       service: http
       state: enabled
       permanent: true
       immediate: true
    - name: Create Contents
      ansible.builtin.copy:
        src: index.html
        dest: /var/www/html
...

> echo "Hello world" > index.html

```

2. 플레이북에서 사용하는 속성들을 변수화 (변수 값은 플레이북 안에 작성)
```bash
---
- name: This playbook is webserver config
  hosts: localhost
  become: true
  vars:
    web_service: httpd
    flag: true
    src: index.html
    dest: /var/www/html
  tasks:
    - name: Package Install
      ansible.builtin.yum:
        name: "{{ web_service }}"
        state: latest
    - name: Service Enabled
      ansible.builtin.service:
        name: "{{ web_service }}"
        state: started
        enabled: "{{ flag }}"
    - name: Firewall Setting
      ansible.posix.firewalld:
       service: http
       state: enabled
       permanent: "{{ flag }}"
       immediate: "{{ flag }}"
    - name: Create Contents
      ansible.builtin.copy:
        src: "{{ src }}"
        dest: "{{ dest }}"
...
```

3. include_vars 모듈을 사용해서 (변수 값을 별도의 파일에서 불러오기)
```bash
---
- name: This playbook is webserver config
  hosts: ansible-node1
  become: true
  tasks:
    - name: Include Vars
      include_vars: vars/web_vars.yaml
    - name: Package Install
      ansible.builtin.yum:
        name: "{{ web_service }}"
        state: latest

[vagrant@ansible-controller-prac playbook]$ cd vars
[vagrant@ansible-controller-prac vars]$ vi web_vars.yaml

  vars:
    web_service: httpd
    flag: true
    src: index.html
    dest: /var/www/html
```

4. 패키지 설치 / 서비스 활성화 / 방화벽 설정 / 파일 복사 모두 별도의 작업 파일로 작성 후 불러오기로 실행
```bash
[vagrant@ansible-controller-prac playbook]$ mkdir tasks
[vagrant@ansible-controller-prac playbook]$ vi tasks/pkg.yaml

- name: Package Install
  ansible.builtin.yum:
    name: "{{ web_service }}"
    state: latest

[vagrant@ansible-controller-prac playbook]$ vi tasks/svc.yaml

- name: Service Enabled
  ansible.builtin.service:
    name: "{{ web_service }}"
    state: started
    enabled: "{{ flag }}"

[vagrant@ansible-controller-prac playbook]$ vi tasks/frw.yaml

- name: Firewall Setting
  ansible.posix.firewalld:
    service: http
    state: enabled
    permanent: "{{ flag }}"
    immediate: "{{ flag }}"

[vagrant@ansible-controller-prac playbook]$ vi tasks/cc.yaml

- name: Create Contents
  ansible.builtin.copy:
    src: "{{ src }}"
    dest: "{{ dest }}"

[vagrant@ansible-controller-prac playbook]$ vi webserver.yaml

---
- name: This playbook is webserver config
  hosts: ansible-node1
  become: true
  tasks:
    - name: Include Vars
      include_vars: vars/web_vars.yaml
    - import_tasks: tasks/pkg.yaml
    - import_tasks: tasks/svc.yaml
    - import_tasks: tasks/frw.yaml
    - import_tasks: tasks/cc.yaml
...
```

5. 플레이북을 main.yaml 로 새로 만들면서 노드1에는 웹서버 구성, 노드2에는 데이터베이스 서버 구성
    1) import_playbook으로 플레이북 2개 가져오기
    2) 불러오기하는 플레이북은 작업 파일들을 불러오기
```bash
[vagrant@ansible-controller-prac playbook]$ cp webserver.yaml dbserver.yaml
[vagrant@ansible-controller-prac playbook]$ vi dbserver.yaml

---
- name: DB Server
  hosts: ansible-node2
  become: true
  tasks:
    - name: Include Vars
      include_vars: vars/db_vars.yaml
    - import_tasks: tasks/pkg.yaml
    - import_tasks: tasks/svc.yaml
    - import_tasks: tasks/frw.yaml
...


[vagrant@ansible-controller-prac playbook]$ vi tasks/pkg.yaml
[vagrant@ansible-controller-prac playbook]$ cp vars/web_vars.yaml vars/db_vars.yaml

[vagrant@ansible-controller-prac playbook]$ vi main.yaml

---
- import_playbook: webserver-module.yaml
- import_playbook: db-module.yaml


```
