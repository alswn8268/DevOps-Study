- Ansible 플레이북은 반복 가능하고 재사용 가능하면 간단한 구성 관리부터 여러 호스트에 복잡한 애플리케이션을 배포하는데 매우 적합함
- 작업을 두 번이상 실행해야하는 경우 Ad-hoc 명령을 사용하지 않고, 플레이북을 작성하고 Git과 같은 소스 제어를 사용하기를 권장함

# 4.1 플레이북 구문
- 플레이북은 YAML 형식으로 표현됨

## 4.1.1. YAML 기본
- Ansible 플레이북의 YAML 파일은 항상 목록(List)으로 시작되며, 목록의 각 항목은 해시(Hash) 또는 사전(Dictionary)이라는 키/값 쌍을 가지고 있음
- 선택적으로 YAML 파일의 시작은 ---로, 파일의 끝은 ...으로 끝을 나타낸
- 들여쓰기 수준은 동일해야 하며, 공백문자로만 사용함. 탭은 구문 오류를 발생시키기 때문에 일반적으로 공백 2칸을 사용함

```bash
vim ~/.vimrc # vim 에디터로 YAML 파일 작성 시 세팅

syntax on
autocmd FileType yaml setlocal ts=2 sts=2 sw=2 ai et
```
## 4.1.2 목록
- 목록은 -와 공백으로 시작하고, 들여쓰기 수준은 동일해야 함

## 4.1.3 사전
- 사전은 키/값 쌍을 가지고 있다. 키와 값은 :으로 구분되며 : 뒤에 반드시 공백이 와야 함. {} 사용

## 4.1.4 부울 값
- yes = true = True = TRUE
- no = false = False = FALSE

## 4.1.5 여러 줄 값
- include_newlines: |
- fold_newlines: >

```bash
vim playbook.yaml

---
# This is sample
```

### 플레이북 명령 실습

1. copy 모듈로 컨트롤 노드의 /etc/hosts 파일을 /tmp 디렉토리에 복사하기
```bash
[vagrant@ansible-controller second]$ vim test1.yaml

---
- name: This play is file copy
  hosts: node2
  tasks:
    - name: hosts file copy
      ansible.builtin.copy:
        src: /etc/hosts
        dest: /tmp
...

[vagrant@ansible-controller second]$ ansible-playbook test1.yaml
```
2. file 모듈로 복사한 hosts 파일의 권한을 666으로 설정
```bash
[vagrant@ansible-controller second]$ vim test2.yaml

---
- name: test2
  hosts: node2
  tasks:
    - name: host 666
      file:
        dest: /tmp/hosts
        mode: '0666'
...

[vagrant@ansible-controller second]$ ansible-playbook test2.yaml
```

3. file 모듈로 /tmp/new-file 이라는 빈 파일을 생성
```bash
[vagrant@ansible-controller second]$ vim test3.yaml

---
- name: test3
  hosts: node2
  tasks:
    - name: create new-file
      file:
        dest: /tmp/new-file
        state: touch
...

[vagrant@ansible-controller second]$ ansible-playbook test3.yaml
```

4. file 모듈로 /tmp/new-dir 이라는 디렉토리를 생성
```bash

  hosts: node2

```

5. file 모듈로 /tmp/new-file 이라는 파일 삭제
```bash

---
- name: test5
  hosts: node2

    - name: remove new-file

        dest: /tmp/new-file
        state: absent

```

6. file 모듈로 /tmp/new-dir 디렉토리의 소유자를 vagrant, 소유 그룹을 wheel로 변경
```bash

        state: directory
```

#### 웹서버 세팅 실습
```bash
[vagrant@ansible-controller ~]$ vim webserver.yaml
[vagrant@ansible-controller ~]$ ansible-galaxy collection install ansible.posix

---
- name: This playbook is webserver config
  hosts: webserver
  tasks:
    - name: Package Install
      ansible.builtin.yum:
        name: httpd
        state: latest
    - name: Service Enabled
      ansible.builtin.service:
        name: httpd
        state: started
        enabled: true
    - name: Firewall Setting
      ansible.posix.firewalld:
       service: http
       state: enabled
       permanent: true
       immediate: true
    - name: Create Contents
      ansible.builtin.copy:
        src: index.html
        dest: /var/www/html
...
```
