## 용어 정리
- `네트워크`: 시스템 간의 연결 구성을 통해 작업을 지원
- `시스템`: CPU 등의 하드웨어를 통해 작업하는 장치
- `스토리지`: 데이터를 저장하는 장치
- `서버`: 서비스를 제공하는 시스템
- `플랫폼`: 특정 작업을 위한 기반이 되는 시스템 및 네트워크 자원들
- `인프라`: 시스템 + 네트워크 + 스토리지 등의 자원의 집합
- `온프레미스`: 직접 구성한 인프라 (데이터 센터)

- `가상화`: 클라우드의 기반 기술
물리적인 리소스를 논리적으로 추상화
-> 하나인 것을 여러 개처럼 나눠 주거나, 여러 개를 하나 처럼 합쳐주거나, 형태를 변형해주는 방식들

- `클라우드`: 사용자가 원하는 대로 시스템 리소스를 서비스 제공
    - `퍼블릭 클라우드`: 사용한 만큼 비용 지불, 업체가 대신 구성/관리해줌
    - `프라이빗 클라우드`: 내가 직접 구성/관리
    - `하이브리드 클라우드`: 퍼블릭 + 프라이빗
    - `멀티 클라우드`: 퍼블릭 + 퍼블릭

## 1.1.2 클라우드 컴퓨팅 이점
- `민첩성`: 광범위한 기술에 쉽게 접근할 수 있어 거의 모든 것을 빠르고 혁신적으로 구축할 수 있음
- `탄력성`: 필요한 만큼만 자원을 할당받아 사용하면 되기 때문에, 비즈니스 요구가 가변적인 상황에서 자원을 손쉽게 확장, 축소할 수 있음
- `비용 절감`: IT 자원을 사용한 만큼만 비용을 지불하면 됨

## 1.1.3 클라우드 컴퓨팅 서비스 유형
- `IaaS`: 인프라 형태로 제공되는 클라우드 서비스. 클라우드 공급자는 인프라 영역을 관리하고 서비스를 제공하며, 클라우드 사용자가 나머지 영역을 직접 관리하는 구조
- `PaaS`: 플랫폼 형태로 제공되는 클라우드 서비스. 클라우드 사용자는 애플리케이션 영역만 담당하고 나머지는 클라우드 공급자가 관리 및 제공하는 구조.
- `SaaS`: 소프트웨어 영역까지 클라우드 공급자가 관리 및 제공하는 서비스. 클라우드 공급자가 모든 것을 제공하고 클라우드 사용자는 서비스만 받는 구조
