### 디플로이먼트 실습 과정
  1. 디플로이먼트 생성
  2. 기본적인 파드 관리 확인 -> 파드 및 레플리카셋 삭제 후 상태 확인
  3. 파드의 설정을 수정해서 업데이트(배포) 확인
    -> 실시간 모니터링으로 교체 과정도 확인
    -> rollout 명령어로도 확인
  4. --record 옵션과 annotation 설정으로 버전 관리시 기록 남기기
  5. 파드/레플리카셋/디플로이먼트의 변화 과정 확인


```sh
vagrant@kube-control1:~$ tar cfz practice.tar.gz controller/ custom/ network/ pod/ volume/
vagrant@kube-control1:~/controller$ cat myapp-deploy.yaml 

vagrant@kube-control1:~/controller$ vim myapp-deploy-v1.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: myapp-deploy
spec:
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 1
      maxSurge: 1
  minReadySeconds: 20
  replicas: 3
  selector:
    matchLabels:
      app: myapp-deploy
  template:
    metadata:
      labels:
        app: myapp-deploy
    spec:
      containers:
        - name: myapp
          image: ghcr.io/nobreak-labs/go-myweb:alpine

vagrant@kube-control1:~/controller$ kubectl create -f myapp-deploy-v1.yaml 

vagrant@kube-control1:~/controller$ kubectl get deployments.apps
NAME           READY   UP-TO-DATE   AVAILABLE   AGE
myapp-deploy   0/3     3            0           16s

vagrant@kube-control1:~/controller$ kubectl get rs
vagrant@kube-control1:~/controller$ kubectl get pod

vagrant@kube-control1:~/controller$ kubectl describe rs | grep Controlled
Controlled By:  Deployment/myapp-deploy

vagrant@kube-control1:~/controller$ kubectl describe deployments.apps
```

```sh
vagrant@kube-control1:~/controller$ vim myapp-deploy-v2-annotation.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: myapp-deploy
  annotaitons:
    kubernetes.io/change-cause: go-myweb:v2 image using
spec:
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 1
      maxSurge: 1
  minReadySeconds: 20
  replicas: 3
  selector:
    matchLabels:
      app: myapp-deploy
  template:
    metadata:
      labels:
        app: myapp-deploy
    spec:
      containers:
        - name: myapp
          image: ghcr.io/nobreak-labs/go-myweb:alpine

vagrant@kube-control1:~/controller$ kubectl apply -f myapp-deploy-v2-annotation.yaml

vagrant@kube-control1:~/controller$ kubectl rollout history deployment myapp-deploy

vagrant@kube-control1:~/controller$ kubectl rollout undo deployment myapp-deploy --to-revision 1
```
