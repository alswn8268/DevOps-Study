### 쿠버네티스의 볼륨
- 파드는 데이터를 영구저장하지 않는다.
- 파드 안에 컨테이너가 여러 개 있을 경우, 각 컨테이너는 서로 데이터(파일)가 공유되지 않는다.
- 볼륨을 사용하면 영구저장 혹은 공유가 가능

볼륨의 종류
1. `emptyDir`: 데이터를 영구저장하지 않음
  하나의 파드 안에 있는 여러 컨테이너가 서로 데이터 공유가 필요할 때 사용
  -> 임시로 로컬 스토리지의 특정 영역을 사용
2. `hostPath`: 데이터 영구저장
  파드가 실행 중인 노드의 로컬 스토리지 사용
  주로 특정 노드에 있는 데이터를 파드에 공유 시 사용
  파드의 데이터를 영구저장하기 위해서도 사용 가능
3. `NFS 등`: 각종 스토리지 서비스(제품)들을 사용해서 데이터를 영구저장하기 위해 사용
  -> 파드 생성 시 함께 생성, 삭제시 함께 삭제
  데이터를 영구저장하기 위해 사용
4. `PersistentVolume(PV)`, `PersistentVolumeClaim (PVC)`
  : 스토리지 서비스를 이용한 볼륨을 파드와 별개로 생성하고 관리하고자 할 경우 사용
5. `PV/PVC` + `StorageClass (SC)` 사용 시
  -> 동적 프로비저닝 방식의 구성이 가능

### NFS 볼륨

.|emptyDir|hostPath|NFS|
|---|---|---|---|
|공유|컨테이너끼리|노드와 파드|파드와 파드(NFS 서버)|
|저장|X|특정 노드에만|NFS 서버에 저장 -> 공유|

1. NFS 서버 구축 
```sh
$ sudo apt update
$ sudo apt install -y nfs-kernel-server (-> 패키지 설치 / 우분투 기준)
$ sudo mkdir /srv/nfs-volume
$ sudo vim /etc/exports 
$ sudo exportfs -r  (-> 공유 설정)
$ sudo vim /srv/nfs-volume/index.html (-> 공유할 파일 생성)
```
2. 각 노드에 NFS-client 도구(마운트 도구)를 설치
```sh
$ sudo apt update
$ sudo apt install -y nfs-common (-> 클라이언트 도구 설치)
```
3. 파드 생성
```sh
$ kubectl create -f myapp-rs-nfs.yaml -f myapp-svc-nfs.yaml
```

### PV / PVC

```sh
(kubespray) vagrant@kube-control1:~/volume$ vim myapp-pv-nfs.yaml

apiVersion: v1
kind: PersistentVolume
metadata:
  name: myapp-pv-nfs
spec:
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteMany
  persistentVolumeReclaimPolicy: Retain
  nfs:
    path: /srv/nfs-volume
    server: 192.168.56.11

(kubespray) vagrant@kube-control1:~/volume$ vim myapp-pvc-nfs.yaml

apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: myapp-pvc-nfs
spec:
  resources:
    requests:
      storage: 1Gi
  accessModes:
    - ReadWriteMany
  volumeName: myapp-pv-nfs

(kubespray) vagrant@kube-control1:~/volume$ kubectl create -f myapp-pv-nfs.yaml -f myapp-pvc-nfs.yaml

(kubespray) vagrant@kube-control1:~/volume$ kubectl delete pvc myapp-pvc-nfs  # pvc 먼저 삭제해야 함
persistentvolumeclaim "myapp-pvc-nfs" deleted
(kubespray) vagrant@kube-control1:~/volume$ kubectl delete pv myapp-pv-nfs 
persistentvolume "myapp-pv-nfs" deleted
```

파드 - 애플리케이션 실행
PVC - 파드와 PV를 연결하는 매개체
PV - 스토리지에 할당받은 공간을 쿠버네티스에서 관리하는 단위
SC - 어떤 스토리지에 PV를 생성할 지 지정하는 용도
