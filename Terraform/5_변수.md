# 5.1 입력 변수
```sh
variable "my-vars" {
        type = string
        default = "hello"
        description = "test variable block"
        # validation = ["hello", "bye"]
        sensitive = false
}

output "my-output" {
#        value = "test output"
#        value = var.my-vars
        value = aws_instance.my-instance.id
}

[vagrant@ansible-controller ~]$ terraform apply -var "my-vars=bye"

[vagrant@ansible-controller ~]$ vi myvars.tfvars
my-vars = "myfile"

[vagrant@ansible-controller terraform]$ vi vm.tf
resource "aws_instance" "my-instance" {
  ami           = "ami-04fcc2023d6e37430"
  instance_type = "t2.micro"
  tags = {
    Name = "my-vm"
  }
}
variable "my-vars" {
        default = "hello"
}
```

1. 인스턴스 이름을 "my-vm" -> var.my-vars 수정 후에 terraform apply 명령어 실행
2. terraform apply -var my-vars=bye 방식으로 실행
3. myvars.tfvars 파일을 생성해서 내용은 my-vars = "myfile"로 저장 후 terraform apply 명령어 실행
4. variable 블록에서 default 항목 제거 및 myvars.tfvars 파일 제거 후 terraform apply 명령어 실행

# 5.2 로컬 값
```sh
[vagrant@ansible-controller terraform]$ vi vm.tf

resource "aws_instance" "my-instance" {
resource "aws_instance" "my-instance" {
#  ami           = "ami-04fcc2023d6e37430"
  ami = data.aws_ami.my-img.id
  instance_type = "t2.micro"
  tags = {
    Name = var.my-vars
    Test_local = local.my-local
  }
}
```
```sh
data "aws_ami" "my-img" {
        most_recent = true
        owners = ["amazon"]
        filter = {
                name = "name"
                values = ["amzn2-ami-hvm-*-x86_64-ebs"]
        }
}
```
```sh
variable "my-vars" {
        default = "hello"
}
locals {
        my-local = concat(vars.my-vars, "-bye")
}
```

# 5.3 데이터 소스

입력변수(variable) 예시

1. 리전이름을 변수 선언 및 사용 (기본값 선언 및 사용)
```sh
variable "aws_region" {
  description = "AWS region"
  type        = string
  default     = "ap-northeast-2"
}
```
```sh
terraform {
  required_providers {
    aws = {
      source = "hashicorp/aws"
      version = "6.25.0"
    }
  }
}
```
```sh
provider "aws" {
  profile = "default"
  region  = var.aws_region
}
```


2. 인스턴스 유형을 변수 선언 및 사용 (값 제한 설정)
```sh
variable "instance_type" {
  description = "EC2 instance type"
  type        = string
  validation {
    condition     = var.instance_type == "t2.micro" || var.instance_type == "t3.micro"
    error_message = "instance_type 변수는 반드시 't2.micro' 또는 't3.micro' 중 하나여야 합니다."
  }
}
```
```sh
resource "aws_instance" "my-vm" {
  ami                    = xxx
  instance_type          = var.instance_type

  tags = {
    Name = "my-instance"
  }
}
```
---
출력변수(output) 예시
1. 일반 문자열 출력
```sh
output "my-output" {
  value = "Terraform Test Complete"
}
```

2. 특정 속성값 출력 (인스턴스에 할당된 퍼블릭IP 출력)
```sh
output "instance_public_ip_a" {
  description = "Public IP of Instance"
  value       = aws_instance.instance_a.public_ip
}
```

데이터소스 예시
```sh
data "aws_ami" "ubuntu_linux" {
  most_recent = true
  owners      = ["amazon"]

  filter {
    name   = "name"
    values = ["ubuntu/images/hvm-ssd/ubuntu-focal-20.04-amd64-server-*"]
  }
}
```
```sh
resource "aws_instance" "data-vm" {
  ami                    = data.aws_ami.ubuntu_linux.image_id
  instance_type          = var.instance_type

  tags = {
    Name = "data-instance"
  }
}
```
