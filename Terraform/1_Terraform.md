# 1.1 Terraform 소개
- 클라우드, 온프레미스 리소스, 하위 수준의 컴퓨팅, 스토리지, 네트워킹 리소스, 상위 수준의 DNS, SaaS의 배포 및 관리 가능한 코드형 인프라스트럭처 도구
- HCL이라는 구성 파일로 작성 -> 단일 애플리케이션 또는 인프라 전체를 실행하는데 필요한 구성 요소 선언
- 관리자가 원하는 상태에 도달하기 위해 수행할 작업을 선언하고, 실행 계획을 생성한 다음 이를 실행하여 정의된 인프라를 구성함

# 1.2 Terraform의 주요 기능
- 코드형 인프라
  : Terraform은 HCL 구성 파일로 정의하며, 이를 통해 인프라의 구성을 코드화하고 버전 관리를 통해 관리할 수 있음
- 실행 계획
  : Terraform은 구성 파일에 정의된 리소스를 실제 배포하기 전에 "계획" 단계를 통해 수행할 작업을 미리 확인할 수 있음 
- 리소스 종속성
  : Terraform은 구성 파일에 정의된 모든 리소스의 종속성을 확인하고 비종속적인 리소스의 생성을 병렬화함
- 변경 자동화
  : 리소스의 종속성을 통해 리소스가 어떤 순서로 변경되는지 정확히 알 수 있으며, 이는 사람이 직접 구성함으로써 발생하는 오류를 방지

# 1.3 Terraform 워크 플로우
1. 구성 파일 작성
```sh
git init myinfra && cd myinfra # Git 저장소 생성
vi main.tf # 구성 파일 작성
terraform init # Terraform 초기화
```

2. 계획
```sh
terraform plan # 계획 확인
```

3. 적용
```sh
$ terraform apply # 인프라 배포

git push origin master # 원격 저장소로 푸시
```
* 참고) 적용 시 계획 단계가 항상 실행되므로 계획 단계를 생략할 수 있음
