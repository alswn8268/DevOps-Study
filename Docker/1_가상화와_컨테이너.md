# 1.1 가상화 개요
## 1.1.1 가상화 종류
### 1.1.2.1 서버 가상화
  - 서버를 가상의 머신으로 만들어 활용
  - 하드웨어 기술이 발달하면서 리소스 활용률이 낮아져, 리소스 활용률을 높이고자 CPU나 메모리 등을 논리적으로 나누어 사용하는 기술
### 1.1.2.2 네트워크 가상화
  - 네트워크 장비들을 가상 머신으로 구현하여 하나로 통합된 네트워크 환경을 제공
  - NFV(Network Function Virtualization), SDN(Software Defined Networking) 등이 있음
### 1.1.2.3 스토리지 가상화
  - 디스크 RAID처럼 여러 개의 물리적인 드라이브를 하나의 논리적 드라이브처럼 사용하는 기술
  - SDS(Software Defined Storage) 등이 있음
### 1.1.2.4 컨테이너 가상화
  - 호스트 운영체제에서 논리적인 구역을 만들어 서로 독립적인 어플리케이션을 실행하는 기술

# 1.2 서버 가상화
## 1.2.1 서버 가상화 개요
  - 하드웨어 자원을 논리적으로 나누어 여러 개의 가상 머신을 생성하고 운영체제를 설치하여 사용하는 기술
  - 주로 소프트웨어 파티셔닝 방식으로 나누는데, 이 때 사용되는 소프트웨어를 하이퍼바이저(Hypervisor) 라고 함
## 1.2.2 하이퍼바이저(Hypervisor)
  - 호스트가 소프트웨어 파티셔닝을 할 수 있게 만들어주는 소프트웨어
  - 가상 머신의 리소스 관리 뿐만 아니라 서로 독립적인 환경을 사용할 수 있도록 리소스간 접근 방지 기능도 가지고 있음

# 1.3 리눅스 컨테이너
## 1.3.1 리눅스 컨테이너 개요
  - 컨테이너 가상화 기술 활용
  - 리눅스 컨테이너는 리눅스 운영체제의 기능을 활용하여 어플리케이션을 격리된 환경에서 실행하는 기술
## 1.3.2 주 사용 기술
### 1.3.2.1 cgroup
  - control group의 약자
  - 프로세스 또는 스레드를 그룹화하여 관리하는 기능과 시스템 리소스(CPU, 메모리, 디스크 입출력 등)의 사용을 제한하는 기술
### 1.3.2.2 namespace
  - 다수의 오브젝트(PID, 네트워크 파일 시스템 등) 격리
