- it: 컨테이너 내부에서 명령어를 입력할 수 있음
  -> 컨테이너에서 입력이 필요한 경우 (shell)
- d: 컨테이너를 백그라운드에서 실행
  -> 출력 값이 필요 없는 경우
  지속적인 동작을 수행하는 경우 사용

- hello-world: 메시지 출력, 일시적인 동작
- httpd: 메시지 확인 X, 지속적으로 동작
- ubuntu: 지속적으로 동작, 명령어 입력 작업을 위해 사용

### 컨테이너 관리 실습 가이드

```
$ docker container rm -f $(docker container ls -aq)
```
